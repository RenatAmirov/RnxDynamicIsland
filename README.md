# Dynamic Island для Windows

Запусти `DynamicIsland.exe` в корне проекта. Это автономная сборка на C# для Windows 10 версии 1809 или новее и Windows 11, x64. Папку `assets` оставь рядом с приложением. Для встроенного браузера и Island Studio нужен Microsoft Edge WebView2 Runtime.

- Клик по капсуле раскрывает или сворачивает панель.
- После смены трека капсула показывает название и через четыре секунды переходит в режим «Мини». Наведение возвращает название. Задержку и реакции можно менять в Island Studio.
- Темп отрисовки подстраивается под частоту монитора, на котором находится капсула.
- Чтобы перенести островок, потяни за свободную область. При быстром движении фон вытягивается по направлению перетаскивания, после отпускания форма восстанавливается. `FREE` фиксирует позицию, `PIN` снимает фиксацию. Позиция и фиксация сохраняются при перезапуске.
- `Browser` раскрывает встроенную панель с поиском, адресной строкой и собственным профилем. Пункт `Open Spotify Web` открывает Spotify в этой же панели.
- `Open music` открывает локальный аудиофайл и начинает воспроизведение. Если локальный файл не открыт, островок показывает активную медиасессию Windows. Доступность обложки и кнопок зависит от плеера.
- `5 min timer` запускает или останавливает пятиминутный таймер. Остаток виден в компактной капсуле. На ноутбуке панель также показывает заряд батареи.
- Правый клик открывает меню с возвратом к системной медиасессии, сбросом позиции и выходом.

## Island Studio

Открой `SET` в плеере или `Customize island...` в меню правого клика. Вкладки «Мини», «Трек» и «Плеер» позволяют менять порядок и видимость блоков независимо. Стрелки передвигают выбранный блок. Изменения сразу применяются к капсуле и сохраняются автоматически.

- Добавь GIF размером до 4 МБ и разрешением до 1024 × 1024. В мини-капсуле и треке можно задать отдельную настройку анимации, скорость и кадрирование. В плеере остаётся обложка трека.
- Настрой цвета, акцент из обложки, ширину каждого состояния, шрифт, скругление, отступы, непрозрачность и движение. Деформация начинается при захвате свободной части капсулы.
- Сохрани несколько именованных пресетов или экспортируй файл `.island`. Экспорт включает GIF. Импорт открывает пресет в редакторе и применяет его к капсуле.

## Сборка исходников

Установи .NET 10 SDK. Из корня проекта выполни в PowerShell:

```powershell
dotnet build .\source\DynamicIsland.csproj -c Release
```

Чтобы получить автономный EXE со встроенной средой .NET, выполни:

```powershell
dotnet publish .\source\DynamicIsland.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true -p:DebugType=None -o .\publish
```

Готовый `DynamicIsland.exe` и папка `assets` появятся в `publish`.

Версия на C# использует существующие пресеты `.island`, настройки окна и профили WebView2. Исходная версия на C++ лежит в `FromMaxim/Dynamic-Island-Studio-Windows.zip`.
